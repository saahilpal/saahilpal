Hey, I'm **Sahil**. A software engineer based in Bengaluru.

I build backend systems, context engines for AI agents, and developer tools. I like keeping things simple, fast, and free-tier friendly without unnecessary bloat.

When I'm not coding, I'm usually playing chess or reading about systems.

---

### 🛠️ What I'm Building

* **[Synapse](https://github.com/saahilpal/synapse)** — Git-aware context engine for AI coding agents. Uses Tree-sitter AST and SQLite FTS5 to feed exact code context via MCP.
* **[Hush](https://github.com/saahilpal/hush)** — Private email open & click tracker running 100% on Cloudflare Workers + D1. Zero watermarks, zero IP logging, and immune to self-opens.
* **[RAG Doc Analyzer](https://github.com/saahilpal/RAG-DOCAnalyzer)** — Document Q&A system using Gemini embeddings, pgvector, and PostgreSQL with SSE streaming.
* **[LeetSync](https://github.com/saahilpal/LeetSync)** — Chrome extension that auto-saves LeetCode solutions directly to GitHub with problem context.
